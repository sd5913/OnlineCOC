组件与数据接口

配置包可选 mountAIPage（独立页面）、mountAIConversation（对话页面）、mountAICollapsible（可折叠面板）；会话管理可用 mountSessionManager、用量统计可用 mountUsage 独立嵌入；自由装配使用 createAITools、mountMarkdown、引用编辑器和指令补全。

房间站点提供 /ai-ui/page.html、/ai-ui/conversation.html、/ai-ui/collapsible.html、/ai-ui/sessions.html，可直接打开或同源 iframe 嵌入。服务商密钥由本机管理器维护。

对话、审核、服务商管理可以分别嵌入。短指令通过授权 API 查找配置及运行时对象；引用固定修订，生成前重新核对。

import { AiClient, mountChat } from '/ai-ui/index.js';
const client = new AiClient();
await client.resume();
const chat = mountChat(container, client, { listTarget: sidebar });
// 页面卸载：chat.destroy(); client.destroy();
