# 树桩镇本地化接入

- 关联文档：[实现](implementation.md)、[本地化工程设计](../../../../docs/plans/localization-engineering-design.md)、[独立工具现状](../../../../docs/current/engineering/localization.md)

0.9.0沿用独立本地化方案的527项UI词条和424项内容词条。源语言为 `zh-CN`，目标为 `en`，语言文件是稳定key→string；目录保存语境、参数类型与分发分类。新增顶栏展开/收起、AI外发/查询说明及PL三栏、浮窗拖动无障碍说明词条。另有3项检定动画开关、播放和结果提示词条，以及21项统一裁决队列文案、3项行动失败说明标签和11项角色影响／通路状态词条；另新增3项行动结果／新线索通知文案。具体服务端失败原因与处理办法目前使用中文，与现有校验错误一致，不计为完整英文覆盖。UI资源公开，content默认受限，不提供HTTP静态下载。正文不作为UI运行标识。

网页顶部可选择简体中文／English；偏好保存在当前标签页的sessionStorage，刷新保留，不影响其他设备。覆盖玩家主要入场流程、导航、状态与背包字段、聊天、操作弹窗，以及十地点公开描述、18个预设的提示／做法／过程、系统叙述、线索与状态变化。中文属性显示为力量、敏捷、意志、生命、经验、坚韧；槽位与布尔／机关状态不直接显示协议字段。KP部分旧编辑提示、服务端校验错误及原生启动窗口仍有中文内容，尚未声称全应用英译完成。角色名、玩家手记、聊天、主持自定义回复和地点文本不自动翻译。

`ui/i18n.js` 是本包消费端适配器，不调用编辑工具或游戏核心。只接受 `stumpsville/ui`，返回 `{text,status,requestedLocale,resolvedLocale,diagnosticCode}`；回退顺序为请求语言→显式别名→源语言→调用方fallback→errorText。随包固定intl-messageformat 12.1.5解析ICU消息，检查参数类型，拒绝含HTML标签的模板。界面数据仍按纯文本转义。

`tools/localization.py` 只消费本机受限content词典：GET `package/state?locale=en`先完成账号投影和权限筛选，再翻译响应副本；POST `package/action?locale=en`翻译系统结果副本。未提供语言时使用中文。只处理明确的系统显示字段，匹配已登记源文本或有限数字模板，不递归改写任意用户字符串，不改变存档、命令参数、行动ID、原始骰或数值。未知／主持改写正文保留原样。已知场景仅返回该账号已获内容；内容词典、词条目录和隐藏剧情不会作为公开UI资源下发。

共享本地化工具当前仅L10N-0基础实现，尚无完整本地化资源构建发布能力。本包按其文件契约维护项目、语言和词条目录，使用包内适配器，不宣称调用尚未存在的正式构建能力。尚未生成该本地化工具的resource-manifest／审校发布物；network-web的不可变资源清单是独立传输协议，不代表译文已审校。随包英文未经工具审校；受限内容适配器支持本包使用的字面文本和数字参数，不是通用ICU发布运行时。

AI 外层助手共有63项 `ai.*` 公开词条，沿用相同语言文件和目录；模型回复、用户需求和服务商标识保持原文，接口错误可能显示稳定错误码。地图角色列表另有14项 `map.*` 公开UI词条；角色名字仍由授权投影提供，不写入公开语言包。

网页模式只在启动组内嵌中文公开UI/元信息，英语通过 `locale-en` 组按需加载；受限内容仍由宿主授权投影。语言、字体和桌面偏好改用可信壳的账号/房间/资源版本隔离存储；本机/LAN继续使用原标签页存储。网页分享管理提示与可信外壳仍为中文。

维护时同时更新对应语言文件及目录，不用玩家文字创建公共词条。UI调用 `t(key, params)`；新增系统内容还须在服务端明确选择显示字段，不能把整个投影递归替换。运行[一屏验收](../../tests/verify_screen.py)、[工作区验收](../../tests/verify_workspace.py)，检查语言键一致、18个预设覆盖、隐藏目录404、用户文字及存档不变。解析器许可见 [messageformat-LICENSE.md](../../ui/messageformat-LICENSE.md)。

新增3项受限地图NPC名称，仅在该玩家已发现并同地点的授权投影中翻译；自定义角色名称保留原文。新版工程原生AI组件的内部提示目前主要为中文，外层导航、标题与设置沿用包侧语言资源，不把组件内部文案计为已完成英文覆盖。

2026-11-19 新增的个人安全菜单措辞、KP 披露说明与升级提示以中文提供；既有英文可匹配词条继续生效，其余回退原文。未将新增内容计入完整英文覆盖；不能为补译把完整行动目录发送给 PL。
