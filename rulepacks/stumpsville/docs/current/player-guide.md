## 1. 身份与目标

你们是一队小鼠冒险者，进入树桩镇调查环境、寻找物资，与遇见的角色交流。每位玩家控制一只小鼠；主持人（KP／GM）描述世界、扮演其他角色并裁定行动。首次体验可直接选择预设角色，经主持审核、标记准备后开场。

**推荐首局目标：「探路取物」。** 主持开场可以这样交代：

> 进镇探一趟路，记下值得告诉同伴的发现，带回一件有用的东西，再一起回到入口集合。

全队共同完成以下三项，即完成这次入门挑战：

1. **记录两条不同的新发现**：调查获得的线索或环境信息都算，在手记或行动日志中留下记录，并告诉同伴。全队合计两条即可，重复观察同一信息不重复计数。
2. **带回一件新物品**：在探索中实际取得一件物品，返回时仍由队员携带；初始装备不计。
3. **全员返回入口**：所有参与的小鼠存活、能够行动，并回到开始的入口地点。

这是依据现有观察、领取、背包和移动功能设计的推荐目标，由主持核对记录、物品和位置后宣布完成；此入门目标由 KP 宣布完成。入口外的返乡过程由主持口述收束。目标不要求战斗、探索所有地点或取得指定宝物。

完成后想继续，可以把下一次目标定为“帮助一位遇见的角色”或“通过交涉解决一次阻碍”，具体条件在行动前与主持说清。

**故事模式「暴雨前的树桩镇」**。在入口观察地面找到主门，检查门框再开门；缺少绳索时可选择“协力撑门”。到庭院与栗婶商议，接下搜救和安置居民的委托。队员可以分工。行动会记入各自的日志，记得把发现告诉同伴。

| 你想争取的结局 | 接下来该找谁 |
| --- | --- |
| 守住家园 | 问工厂如何恢复生产，寻找维修物资，再回庭院签收公共补给 |
| 共同渡险 | 在大厅了解鼠帮的条件，完成供粮或劳务，再想办法联系援队 |
| 安全撤离 | 勘察溪岸路线，和渡工备好渡舟或步道、安排口粮并转移居民 |

三条路线都要救出失联村民。达成安置条件后请 KP 在房间总览清点队员并确认结局。任务可前后交错；已做过的劳务和已取得的物资继续有效。新进场或再次观察时，描述会反映现场余量。

## 2. 怎样玩

**观察与提问 → 说明做法 → 结算后果 → 决定继续或撤退。**

场景里有可调查的环境、人物、物品和危险。先看描述、询问细节，再选择行动；工具、合作和交涉都可能让事情更容易。地点、人物底细和具体解法留待探索。

在玩家桌面查看地图、角色和背包，用“线索手记／行动日志”核对发现与结果。预设按钮提供常见做法；有其他想法时，点“请求 KP 裁决”，说明你要做什么、如何做。

## 3. 记住这些规则

| 要点 | 玩家需要知道的事 |
| --- | --- |
| 三属性 | 力量 STR 管力量与耐受，敏捷 DEX 管反应与灵活，意志 WIL 管意志与魅力 |
| 风险检定 | 掷 d20，不高于当前属性即成功。优势掷两颗取低，劣势取高；例如敏捷 9，掷出 7 成功。安全合理的行动通常无需掷骰 |
| 背包 | 双爪 2 格、身体 2 格、背包 6 格；大物品和负面状态也占格。超载不能跑，所有豁免带劣势 |
| 战斗与伤害 | 攻击成立后直接掷伤害，先减护甲再扣 HP；普通伤害溢出后扣力量并检定是否重伤。力量为零会死亡 |
| 消耗与休息 | 留意食物、光源和物品用量。光源每六个探索轮消耗一格；短休通常恢复 d6+1 HP，休息条件与耗时由主持确认 |

`d20` 是二十面骰，`d6` 是六面骰。聪明的准备、谈判和及时撤退都能帮助队伍达成目标。

当前包可自动处理部分预设行动，仍需 KP 管理页面在线；战斗小窗可直接攻击或尝试逃跑。逃跑掷 d20，不高于当前敏捷即可脱战并留在原地点；失败时对手反击。队友可继续迎战同一对手。自由行动、法术和成长由主持处理。等待结算时查看日志或联系主持。上述规则取自 Mausritter，部分场景做法属于本包适配。
