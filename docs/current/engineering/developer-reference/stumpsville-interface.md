基于本仓库 `rulepacks/stumpsville/`（树桩镇，manifest 版本 `0.9.0`）源码核查。下文路径除链接外均相对该包；KP 为主持，PL 为玩家。只概括当前实现，游戏资料中标注“待终校”的内容仍不是已核实的原版规则。

以下是功能对象树，同类重复卡片合并列出；箭头后为对象职责。网页由 [ui/app.js](../../../../rulepacks/stumpsville/ui/app.js) 组装，入口为 [ui/index.html](../../../../rulepacks/stumpsville/ui/index.html)。

```text
启动面板（tools/panel.py，Python/Tk）
├─ 房间槽位 → 选择、刷新、创建独立存档
├─ 联机模式 / 网卡 / 端口 / AI 开关 → 配置本机、LAN、P2P 或网页启动；AI 默认勾选
├─ 首次准备 → 默认 kp/player1/player2 和密码 12345678，可修改初始密码
├─ 账号管理标签 → 刷新、增加、删除账号及修改密码；操作绑定所选运行房间
└─ 运行控制 → 启停房间、开页面、复制连接、检查连接、查看日志/存档、最小化
网页根节点 #app
├─ 入场页 → 首次设置密码、账号登录、错误反馈
├─ 公共顶栏 → 身份、连接状态、规则速查、偏好、语言、退出、折叠顶栏
├─ 未确认命令条 → 用原命令恢复回执
├─ 未安装状态 → KP在房间页一键初始化并开场，PL等待
├─ PL 页面
│  ├─ lobby 大厅 → 当前角色、建角草稿及审核状态
│  ├─ character/new 建角 → 预设/随机、属性、装备、确认提交
│  ├─ ready 准备 → 角色摘要、准备开关、开场后进入场景
│  ├─ play/scene 工作台
│  │  ├─ 角色栏 → 肖像、等级/经验/勇气、行动能力、属性/HP、光源
│  │  │  └─ 物品栏 → 双手1–2、身体3–4、背包5–10、溢出11–20；卡片操作
│  │  ├─ 场景栏 → 个人观察说明、地点描述、回合、地图与已发现角色
│  │  │  ├─ 地点/通路 → 已知位置、门状态、移动入口
│  │  │  ├─ 行动区 → 当前地点预设、移动、检定、自由申请、事件复核
│  │  │  └─ 场景事实 → 已知机关状态、剩余物资
│  │  ├─ 通讯栏 → 聊天 / 个人 AI 对话切换；本人资料查询、主动披露申请与创作申请
│  │  └─ 可拖动笔记浮窗
│  │     ├─ 线索 → 搜索、标题/地点/正文、私人笔记保存
│  │     └─ 日志 → 未读数、全部/待处理/检定筛选、过程/结果/变化、复核/分享
│  └─ recap 回顾 → 已发布回顾、已知地图、返回场景/大厅
└─ KP 页面（侧栏导航）
   ├─ gm/room 房间 → 全局统计、一键开场、回合、暂停/恢复、自动裁决、备份、连接/成员/分享
   │  └─ 个人已知资料 → 启用服务、旧记录现在揭示、授权列表/撤回
   ├─ gm/rulings 裁决工作台
   │  ├─ 消息队列 → 未读频道及数量，点击切换聊天
   │  ├─ 裁决队列 → 建角批准/退回、宿主等待回应/流程重试或取消
   │  │  ├─ 行动摘要 → 时间、来源、概要、动作；点击浮窗查看角色/地点与完整内容，执行/批准/拒绝，回复默认折叠
   │  │  ├─ AI 待办 → 咨询/转交、原会话、定向揭示、创作申请接收并打开KP私有方案、修改裁决、回执恢复
   │  │  └─ 历史 → 持久行动记录、转AI处理及详情调试
   │  ├─ AI 对话 → 主持咨询、来源裁决/对话引用卡、会话选择、顶栏引用与调试子窗口
   │  └─ 聊天栏 → 当前频道消息与输入
   ├─ gm/map 地图 → 全部地点、通路、角色位置及编辑入口
   ├─ gm/console 控制台
   │  ├─ 房间入口 → 返回集中总览与开场控制
   │  ├─ 角色表 → 属性调整、伤害、休息、授予/移除物品等操作
   │  └─ 生物/遭遇 → 创建生物、伤害/士气、遭遇/反应/战利品骰
   ├─ gm/locations 地点
   │  ├─ 索引/编辑 → 公开描述与 KP 真相分栏、保存草稿、发布、预览
   │  ├─ 通路/库存 → 门状态、有限物品领取、首次器具/鼠帮生成
   │  └─ 角色/揭示 → 地点内角色、向指定玩家显示/隐藏角色或揭示地点
   ├─ gm/library 资料库 → 按配置/数据类型子标签、搜索和详情；导入/预览/激活、随机表、导出包
   ├─ gm/ai-settings AI设置 → 服务、外发范围、玩家权限、自动审批、C 评估依据
   └─ gm/session 场次 → 公开回顾草稿/发布、KP 私密备注
页面外共享层
├─ #dialog → 检定、预设做法、移动、物品操作、伤害/休息、裁决等表单
├─ 聊天浮窗 → 非常驻页聊天；私聊可单独弹出、拖动和最小化
└─ #toast / .dice-popup / .effects-popup → 详见“信息通知”文档
```

新房间显式初始化使用／外发权限，自动审批保持关闭；普通重启不重置。C 评估详情提供显式采纳与过期重检，唯一工程契约见[AI 裁决](../ai-rulings.md#c-类评估与可变依据)。账号管理通过本机宿主控制接口，删除保留角色与历史。

所有裁决可转到 KP 私有 AI 审核会话；原申请是引用材料，转交不执行。裁决详情提供复制定位和可选正文导出，见[调试流程](../../../../rulepacks/stumpsville/docs/current/ai-debugging.md)。

KP窄屏裁决页在队列、AI、聊天间切换；AI组件在同一身份导航中保留，退出销毁。PL 窄屏通过工作台标签切换三栏；旧 `play/character`、`play/journal`、`play/records` 路由会归入工作台。资料库已移除未接线的重复安装按钮；初始化统一由房间页 `session.start` 按需调用 `initialize`。

地图/通知/聊天/AI 分别见 [map.js](../../../../rulepacks/stumpsville/ui/map.js)、[effects.js](../../../../rulepacks/stumpsville/ui/effects.js)、[chat.js](../../../../rulepacks/stumpsville/ui/chat.js)、[ai-embedded.js](../../../../rulepacks/stumpsville/ui/ai-embedded.js)；KP AI 队列见 [keeper-queue.js](../../../../rulepacks/stumpsville/ui/keeper-queue.js)。
