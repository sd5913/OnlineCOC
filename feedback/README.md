# User feedback

Use this folder for observations from people trying OnlineCOC. A short report about where a first-time player got stuck is as welcome as a bug report or a feature suggestion.

Create one Markdown file per report, for example `2026-11-26-first-game.md`. Include enough detail for someone else to try the same steps.

| Detail | What to record |
| --- | --- |
| Setup | Date, version or commit if known, operating system, browser, rulepack and play mode |
| Goal | What the player or GM was trying to do |
| Observation | Steps taken, expected result and what appeared on screen |
| Follow-up | Impact on play, suggested improvement or a link to an issue or fix |

Feedback stored here can be published with the repository. Remove passwords, invite codes, API keys and personal details from text and screenshots.
